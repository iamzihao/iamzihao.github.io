Hermes Attack 精读：如何从 PCIe 明文流量里偷走一个 DNN 模型

Posted on 2026-09-21 Word count in article: 18k Reading time ≈ 32 mins.

论文：Hermes Attack: Steal DNN Models with Lossless Inference Accuracy（USENIX Security 2021）

作者：Yuankun Zhu（UT Dallas）、Yueqiang Cheng（Baidu Security）、Husheng Zhou（VMware）、Yantao Lu（Syracuse University）

概括成一段话：在 CPU 与 GPU 之间那条没有加密的 PCIe 总线上抓包，从 GPU 命令与数据搬运里反推出受害者 DNN 的结构、超参数和全部权重，重建出的模型推理精度与原模型完全一致。

模型文件放在加密盘里、主机开了 SGX、GPU 也独占不共享，模型文件一个字节都没泄露。但模型仍然可能被整个偷走——Hermes Attack 盯上的不是模型文件，而是模型在 GPU 上跑推理时留下的 PCIe 通信痕迹。
