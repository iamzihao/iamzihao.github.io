Rust OS 前置：从 C 到 Rust——变量、类型与 struct

Posted on 2026-09-07 Edited on 2026-09-10 Views: Word count in article: 3.5k Reading time ≈ 6 mins.

学 Rust OS 时会密集碰到 struct、引用、裸指针、unsafe、生命周期这些概念。如果此前没有 Rust 基础，直接读 OS 代码会很吃力。这篇先用 C/C++ 作对照，把你已经会的东西在 Rust 里怎么写过一遍，建立一张 Rust 地图。

本文是 Rust OS 学习系列的前置篇。后续会接着讲引用与借用、属性与内存布局，并把它们综合到《Rust OS 入门：VGA 字符模式》的 Writer 代码上。

📚 基本概念速读

名称 含义 省流
let 声明变量 默认不可变
let mut 声明可变变量 想改就加 mut
: T 变量名后写类型 let x: u8 = 10;
struct 把多个数据组织在一起 类似 C 的 struct
impl 给 struct 添加方法 类似 C++ 的 class 方法
pub 允许模块外访问 默认模块内私有
[T; N] 定长数组类型 [[ScreenChar; 80]; 25]
match 模式匹配 更强大的 switch
Option<T> 有值/无值 Some(v) / None
Result<T, E> 成功/失败 Ok(v) / Err(e)

🔀 match：更强大的 switch

match 是模式匹配，后面学 Option/Result/枚举时它是核心工具，可暂时理解为加强版 switch。

🟢 Option 与 Result：不靠 NULL 和 -1

C 里常用 NULL 表示没有值、用 return -1 表示失败。Rust 不喜欢这种方式，改用两个显式类型：

Some/None/Ok/Err 加上 match，就能强制调用方处理可能没有值或可能失败的情况——这是 Rust 错误处理的基本形态，OS 代码里读取 MMIO 寄存器、解析结构时常会遇到。

✅ 总结

从 C 到 Rust，变量、类型、struct、数组、函数这些零件大多能一一对应，差异主要在三点：变量默认不可变（mut）、类型写在变量名后、最后一个表达式即返回值。真正的分水岭是下一篇要讲的引用与所有权。

下一篇接着讲这条核心主线：&（借用）→ &mut（可变借用）→ 裸指针 → unsafe → 生命周期，把内存到底归谁管讲清楚。
